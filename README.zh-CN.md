# EasyRap

**将1–2张照片变成一段个性化说唱音乐视频。**

[访问官网](https://easyrapvideo.com/) · [查看价格](https://easyrapvideo.com/pricing) · [English](README.md)

EasyRap 是网页端 AI 工具，可制作生日 rap、友好吐槽、宠物 rap、双人 rap，或使用自己的创意。上传照片，选择风格和场景，可选填写简短歌词，再选择5、10或15秒，确认积分费用后生成；成功后可在 My Videos 播放或下载 MP4。

- **付费方式：**积分包或订阅；目前没有免费成片试用。准备照片和参数不扣视频积分，每次新生成单独计费。
- **能力限制：**不支持上传参考音频、音乐文件、Suno/Udio链接或声线克隆；不保证逐字歌词与精准口型，AI生成效果可能有差异。
- **素材要求：**使用有权使用的图片；真实人物必须是已同意的成年人，不冒用他人身份或虚构代言。
